# External and analytic benchmarks

These checks isolate parts of the calculation from the new Einstein--Vlasov matter-led pole.

## 1. Published Schwarzschild QNM

The vacuum Zerilli/ECS solver gives

`M omega = 0.3736716843524924 -0.0889623156416965 i`.

Cardoso et al., Phys. Rev. D 99, 104077 (2019), explicitly quote the standard gravitational Schwarzschild `ell=2` fundamental as

`M omega = 0.3736716844180418 -0.0889623156889357 i`.

The absolute complex difference is `8.080e-11`, and the relative complex difference is `2.103e-10`.

The same standard value is consistent with the Leaver continued-fraction literature and the review by Berti, Cardoso & Starinets, Class. Quantum Grav. 26, 163001 (2009).

## 2. Closed-form retarded continuation

For `rho(nu)=1+nu` on `0<=nu<=1`,

`C(z)=(z+1)[log(z)-log(z-1)]-1`.

On the retarded second sheet crossed through the support,

`C_II(z)=C(z)-2*pi*i*(1+z)`.

The same piecewise-linear/Plemelj implementation used by the publication spectral module reproduces this result with maximum absolute error `2.311e-14`.

## 3. Exact Schwarzschild photon-sphere limit

For the Schwarzschild null circular orbit,

`r_ph=3M`, `B_c^2/M^2=27`, and `M Omega_ph=1/sqrt(27)`.

The two independently constructed cold Einstein--Vlasov sequences converge to these exact orbital invariants. At `N=80`:

- reference family: relative `B^2` error `1.148e-03`, relative `Omega_phi` error `5.487e-04`;
- second family: relative `B^2` error `4.852e-04`, relative `Omega_phi` error `2.471e-04`.

The fitted errors are approximately second order in both families.

## Literature-context checks that are NOT used as quantitative benchmarks

Laeuger et al., Phys. Rev. D 112, 084042 (2025), independently find new weakly damped polar QNMs generated by coupling metric perturbations to a dynamical thin matter shell. Their surface-fluid shell, mass convention, shell radius and equation of state differ from the collisionless extended atmosphere here, so no frequency matching is claimed.

Günther, Rein & Straub, Arch. Ration. Mech. Anal. 249, 54 (2025), rigorously prove existence and linear stability for related small Vlasov shells around a Schwarzschild black hole. Their theorem does not directly establish stability of the massless finite-q families used in this manuscript, so it is cited as independent support for the broader class rather than as a benchmark of the new pole.
