# Spectral cache data

The global QNM and source-coupling calculations use cached spectral-node arrays generated by the smooth Einstein--Vlasov background and action--angle pipeline.

Binary spectral caches are intentionally not stored in this compact Git repository. The publication-resolution `q = 0.10` spectral-node array used by the retarded constitutive response and blind multiple-shooting reproduction is supplied with the manuscript as **Supplementary Data 1**. Its expected SHA256 checksum is recorded in `verification/blind_multiple_shooting/SPECTRAL_DATA_SHA256.txt`.

Compact numerical values needed to inspect the reported roots, convergence tests, source residues and figure data are available under `../results/`.
