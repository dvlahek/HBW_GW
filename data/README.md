# Spectral cache data

The global QNM and source-coupling calculations use cached spectral-node arrays generated by the smooth Einstein--Vlasov background and action--angle pipeline. These binary arrays are intentionally not stored in this minimal Git repository.

The publication archive will contain the exact caches used for the accepted `q = 0.10` and `q = 0.20` calculations together with the remaining family data. The archival DOI will be added here when the dataset is deposited.

The compact numerical values needed to inspect the reported results are already available in `../results/`.
